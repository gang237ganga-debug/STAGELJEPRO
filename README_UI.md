# LJE — Prototype final unifié

Cette version conserve les fonctionnalités métier du prototype et ajoute uniquement une amélioration de l'ergonomie :

- menu burger depuis le header ;
- Profil déplacé dans le menu burger ;
- barre mobile simplifiée pour libérer une place dédiée aux Dons ;
- bouton « Faire un don » mis en avant côté Membre ;
- bouton « Dons » mis en avant côté Admin ;
- menu burger contextualisé selon le rôle ;
- mode sombre/clair persistant sur Web et mobile ;
- respect de la navigation et des fonctionnalités existantes ;
- tous les fichiers restent au même niveau, dans un seul dossier.

Le prototype reste autonome et utilise sa BDD JavaScript/localStorage comme dans la version précédente.

- Menu burger mobile Admin : ajout de « Changer d’interface » pour passer vers Web Membre ; cette option est absente du menu Membre.
- Navigation mobile Admin : permutation des positions « Dons » et « Accueil » (Dons en première position, Accueil en troisième).
